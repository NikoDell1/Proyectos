# Aventura Travel - Agencia de Viajes

Proyecto integrador del Taller práctico de Bootstrap 5.

## Descripción
Sitio web comercial responsive para una agencia de viajes. Incluye catálogo de destinos (más de 8), paquetes turísticos con precios y servicios, promociones, filtros, formulario de reservas simuladas y contacto.

**Importante:** Es un proyecto académico. No se procesan pagos ni reservas reales.

## Tecnologías
- HTML5
- CSS3
- Bootstrap 5.3.9 (CDN)
- JavaScript (vanilla)
- Font Awesome (CDN)

## Estructura del proyecto
```
agencia-viajes/
├── index.html
```

## Funcionalidades principales
- Navbar responsive fija
- Hero section
- Catálogo de 10 destinos con filtros por categoría (Playa, Ciudad, Naturaleza, Aventura)
- Paquetes turísticos con selección
- Promociones
- Formulario de reserva validado con cálculo de total (personas, seguro, descuentos)
- Resumen de reserva simulada
- Modal de detalles
- Diseño responsive (móvil, tablet, desktop)

## Instrucciones de uso
1. Abre `index.html` en un navegador (o sirve con un servidor local).
2. Navega por las secciones.
3. Filtra destinos.
4. Selecciona un paquete.
5. Completa el formulario de reserva y envía para ver el resumen y total.
